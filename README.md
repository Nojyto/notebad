# **Notebad - not a bad text editor**

**Notebad** is a simple text editor built using **Electron**. This project allows you to create, open, edit, and save text files seamlessly, with a focus on simplicity and responsiveness.

## **Development Setup**

Follow these steps to set up the development environment and run the project locally:

```bash
git clone https://github.com/Nojyto/notebad.git
cd notebad
```

Make sure you have Node.js and npm installed. Then, run:

```bash
npm install
```

To start the development environment with live reload:

```bash
npm run dev
```

## **Building the Application**

The build process generates binaries for your operating system. The default OS is detected automatically.

```bash
npm run build
```

## **Technologies Used**

- **Electron**: Desktop application framework.
- **React**: Frontend library for UI.
- **TypeScript**: Static typing for better code quality.
- **TailwindCSS**: Utility-first CSS framework.
